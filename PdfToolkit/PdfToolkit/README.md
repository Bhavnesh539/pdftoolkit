# PDF Toolkit (Android, Kotlin + Jetpack Compose)
Open this folder in Android Studio (Koala or newer), let Gradle sync, press Run.
Features: images→PDF (crop via uCrop, filters: gray/B&W/sepia/bright), compress PDF, merge PDFs,
open Word/Excel/PPT via installed apps, share, save to Downloads.
Notes: compress/merge rasterize pages (text is no longer selectable). Min Android 10 (API 29).
